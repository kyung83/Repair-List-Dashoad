# Tire position workflow

Technicians working a tire-related repair on a truck or trailer must record the exact wheel position before the Shop UI allows **REPAIRED**.

## Truck positions

- Axle 1 steer: `A1L`, `A1R`
- Axle 2 drive: `A2LO`, `A2LI`, `A2RI`, `A2RO`
- Axle 3 drive: `A3LO`, `A3LI`, `A3RI`, `A3RO`

## Trailer positions

- Axle 1: `A1LO`, `A1LI`, `A1RI`, `A1RO`
- Axle 2: `A2LO`, `A2LI`, `A2RI`, `A2RO`

`L` = left, `R` = right, `I` = inner, `O` = outer.

More than one position can be selected for one repair. The saved position rows remain attached to the repair as permanent history after the repair is completed.
